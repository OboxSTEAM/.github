# OboxSTEAM

**Khám phá. Sáng tạo. Tỏa sáng.**  
Explore. Create. Shine.

OboxSTEAM brings hands-on STEAM learning together with a digital record of each student's journey, from discovering a course to building a portfolio of projects and achievements.

[![Animated overview of the OboxSTEAM learning journey, web platform, mobile check-in, and student portfolio](assets/obox-showreel-preview.gif)](assets/obox-showreel.mp4)

**[Watch the full 45-second showreel](assets/obox-showreel.mp4)** · Silent video, 720p

### What we're building

- **Learn by doing:** courses, learning paths, and real-world projects across science, technology, engineering, arts, and mathematics.
- **Capture progress:** student portfolios that bring work, milestones, and achievements together.
- **Stay connected:** web and mobile experiences for students, families, and mentors.
